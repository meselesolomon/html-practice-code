Mekelle University

Faculty of Computing — Academic Programs & Web Technologies

Computer Science (CS)

Focuses on the theoretical foundations of computation, algorithms, artificial intelligence, and systems architecture.


Core Topics:

  • Data Structures and Algorithms
  • Operating Systems
  • Artificial Intelligence & Machine Learning
  • Compiler Design

Software Engineering (SE)

Emphasizes systematic approaches to the design, development, testing, and maintenance of large-scale software systems.


Core Topics:

  • Software Requirement Engineering
  • Design Patterns & Architecture
  • Software Quality Assurance & Testing
  • DevOps and CI/CD Pipelines

Information Systems (IS)

Bridging business operations and technology by managing data systems to support organizational goals.


Core Topics:

  • Enterprise Resource Planning (ERP)
  • Business Process Management
  • IT Project Management
  • Database Management Systems

Information Science (ISc)

Concerned with the collection, manipulation, storage, retrieval, and dissemination of recorded information.


Core Topics:

  • Information Retrieval & Search Engines
  • Knowledge Management Systems
  • Digital Libraries
  • Data Analytics & Information Ethics

Information Technology (IT)

Focuses on meeting the technology needs of businesses and users through network infrastructure and system administration.


Core Topics:

  • Network Administration & Security
  • System Integration
  • Web and Mobile Technologies
  • Cybersecurity Fundamentals

Modern Web Development Technologies

Technologies used to build robust frontend and backend web applications.


Frontend Stack

  • HTML5 & CSS3: Structure and design
  • JavaScript: Client-side scripting
  • React.js / Vue.js: Modern UI component libraries

Backend Stack

  • Node.js (Express): JavaScript backend runtime
  • Python (Django / FastAPI): Python frameworks
  • PHP (Laravel): Robust server-side framework
  • Java (Spring Boot): Enterprise application framework
